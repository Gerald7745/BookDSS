Book Decision Support System (DSS)

A Flask-based web application that helps users discover personalized book recommendations using a weighted scoring system. 
Users can filter books based on multiple criteria and assign importance weights to different attributes.

Technology Stack

- Backend: Python 3.x, Flask
- Data Processing: Pandas
- Frontend: HTML5, CSS3, 
- **Database**: CSV-based 

Prerequisites
Before you begin, ensure you have the following installed:
- Python 3.7 or higher
- pip
